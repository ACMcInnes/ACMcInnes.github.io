About #

Hi, my name is Andrew, an Australian based full stack(ish) developer with a passion for web design and development, and coding in general. Currently working for a local e-commerce platform. I love building, and breaking things, to figure out how something works.

I enjoy working through a UI and really honing the user experience, planning screens in Figma, building out designs and prototyping. Then getting in and coding it with Next.js and React. Or plain old HTML and CSS. I've checked out most frontend frameworks and can generally make my way around any codebase.

I've also worked using Node.js and Bash to build out small scripts to automate various tasks, and dabbled with some database management and queries. Check out my portfolio below for some of my recent frontend projects.
